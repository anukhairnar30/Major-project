# Major-project
A multimodal deep learning model for classifying 7 types of skin lesions using dermoscopic images and patient metadata. Combines Vision Transformer (ViT), BiLSTM, Attention, and image preprocessing techniques using PyTorch and the HAM10000 dataset.

# Multimodal Skin Cancer Classification

This project focuses on classifying seven types of skin lesions using a multimodal deep learning approach. It combines dermoscopic images with patient metadata, including age, sex, and lesion localization.

The model integrates a pretrained Vision Transformer (ViT), BiLSTM, and Attention mechanism for image feature extraction and combines the extracted features with metadata for final classification.

**Technologies Used:** Python, PyTorch, Vision Transformer (ViT), BiLSTM, Attention Mechanism, OpenCV, and HAM10000 Dataset.

**Test Performance:**
- Test Accuracy: 83.57%
- Macro ROC-AUC: 0.9805

**Note:** This project is intended for research and educational purposes and is not a substitute for professional medical diagnosis.
